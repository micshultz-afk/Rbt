# ShapeSignature — устойчивые сигнатуры Shape для PowerPoint 2013

VBA-модуль для построения компактной строковой сигнатуры фигур (Shape) и быстрой проверки совпадения `True` / `False`. Работает между разными презентациями и не зависит от разрешения экрана, монитора, ОС и размера слайда.

## Почему не Name / Id / Tags

| Свойство | Проблема |
|----------|----------|
| `Shape.Name` | Дублируется при копировании; ненадёжно (см. [PPT FAQ](https://www.rdpslides.com/pptfaq/FAQ01218-The-Name-property-of-PowerPoint-shapes-is-not-reliable.htm)) |
| `Shape.Id` | Уникален только **внутри слайда**; при вставке в другой файл — новый Id |
| `Tags` | Отличны для пометки *внутри* файла, но не переносятся сами по себе как «отпечаток» между чужими презентациями |

Надёжный путь (рекомендации Steve Rindsberg / Stack Overflow): сравнивать **стабильные свойства** объекта — тип, относительную геометрию, оформление, хеш текста — и оставлять в сигнатуре только те, что **уникально отличают** цель от соседей на слайде.

## Независимость от экрана / ОС / размера листа

- Координаты PowerPoint — в **points** (1/72"), не в пикселях → DPI монитора и ОС не влияют.
- Позиция и размер кодируются как **доли** ширины/высоты слайда (`PageSetup.SlideWidth/Height`), квантованные до 0.01%.
- Размер шрифта — относительно высоты слайда.
- Допуск при сравнении геометрии по умолчанию: **±0.5%** стороны слайда.

## Установка (PowerPoint 2013)

1. Откройте презентацию → `Alt+F11` (VBA Editor).
2. `File → Import File…` → импортируйте:
   - `ShapeSignature.bas` (обязательно)
   - `ShapeSignatureExamples.bas` (опционально)
3. Сохраните файл как **`.pptm`** (с макросами).
4. При необходимости разрешите макросы в Trust Center.

Дополнительные ссылки на библиотеки **не нужны** (Dictionary и буфер обмена — через late binding).

## Быстрый старт

### Вариант A — одно выделение (самый простой)

1. Выделите целевую фигуру (или несколько **одинаковых по смыслу**).
2. Запустите макрос **`BuildSignatureFromSelection`**.
3. Скопируйте строку сигнатуры из окна (она также пытается попасть в буфер обмена).

### Вариант B — несколько презентаций (максимальная уникальность)

1. В **активной** презентации выделите целевые фигуры (и/или пометьте их через **`MarkSelectedAsTargets`**).
2. Запустите **`BuildUniqueSignatureFromFiles`**.
3. В диалоге выберите один или несколько `.pptx/.ppt/.pptm` (мультивыбор).
4. Модуль:
   - берёт выделение/метки как **семена**;
   - в других файлах находит аналоги по структурным признакам (тип, относительная геометрия, поворот…; без текста/заливки) **или** по тегу;
   - остальные объекты — **антипримеры**;
   - строит **минимальную** маску, совпадающую на всех целях и не совпадающую с соседями.
5. Скопируйте итоговую строку.

Снять метки: **`ClearTargetMarks`**.

### Проверка

```vba
Dim ok As Boolean
ok = ShapeMatchesSignature(someShape, "S1|…ваша сигнатура…")
' ok = True / False
```

Макрос **`TestMatchSelected`**: выделите фигуру → вставьте сигнатуру → получите `True`/`False`.

## Публичный API

| Метод / функция | Назначение |
|-----------------|------------|
| `MarkSelectedAsTargets` | Пометить выделение для пакетного анализа |
| `ClearTargetMarks` | Снять метки |
| `BuildSignatureFromSelection` | Сигнатура из выделения vs соседи на слайде |
| `BuildUniqueSignatureFromFiles` | Мультивыбор файлов + помеченные цели |
| `ShapeMatchesSignature(ByRef shp As Shape, ByVal sig As String) As Boolean` | Распознавание (только эти 2 аргумента) |
| `MakeSignatureFromShape(shp) As String` | Полная сигнатура одной фигуры (без анализа уникальности) |
| `BuildSignatureFromCollections(targets, others) As String` | Программная сборка без UI |
| `GetShapeFeatureString(shp) As String` | Полный вектор признаков (отладка) |
| `TestMatchSelected` | Ручной тест |

## Формат сигнатуры (сжатый)

```
S1|<mask36>|<fields…>|<crc36>
```

Пример (условный):

```
S1|n|d;1;2c8.1k4.5u.3c;rs;0|a8f3k2
```

- `S1` — версия формата  
- `mask` — битовая маска активных признаков (Base36)  
- `fields` — только активные поля, через `;`, числа в Base36  
- `crc` — FNV-1a по телу строки (защита от обрезки/опечаток)

### Какие признаки умеет модуль

| Бит | Признак | Смысл |
|-----|---------|--------|
| Type | `Shape.Type` | текстовый блок / автофигура / picture / … |
| Auto | `AutoShapeType` или `ContainedType` у placeholder | точный вид фигуры |
| Ph | `PlaceholderFormat.Type` | заголовок, тело, … |
| Geo% | Left/Top/Width/Height относительно слайда | позиция и размер |
| AR | Width/Height | пропорции |
| Rot / Flip | поворот и отражения | ориентация |
| Fill / Line | тип заливки, RGB, линия | оформление |
| Caps | hasText / table / chart / group | возможности объекта |
| TextHash | FNV-1a нормализованного текста | содержимое |
| Font | хеш имени шрифта + относительный размер | типографика |

Алгоритм **жадно** наращивает маску (сначала структурные признаки, затем геометрия/стиль, в конце текст), пока цели не станут уникальны среди антипримеров. В сигнатуру попадают только нужные поля → строка короткая, сравнение быстрое (ранний выход при первом несовпадении).

## Рекомендации для «почти 100%» распознавания

1. Помечайте **несколько экземпляров** одной и той же роли в разных файлах — так отсеются случайные отличия.
2. Если цели визуально одинаковы, но текст разный — не включайте текст в ожидания: модуль сам не возьмёт `TextHash`, если он не стабилен на целях.
3. Если на слайде много клонов с одинаковой геометрией — добавьте в выборку антипримеры из других слайдов/файлов или сделайте цели различимыми (заливка, имя шрифта, фиксированный маркер в тексте).
4. Не полагайтесь на `Name`/`Id` в своих вызовах — используйте только `ShapeMatchesSignature`.
5. Для массового поиска по слайду см. `Example_FindMatchesOnSlide` в `ShapeSignatureExamples.bas`.

## Производительность

- Извлечение признаков — O(1) на фигуру (без экспорта картинок и без UI).
- Сопоставление — разбор строки один раз + последовательные сравнения с early-exit.
- Файлы анализа открываются `WithWindow:=msoFalse` и закрываются после работы.
- Подходит для PowerPoint **2013** (используется только объектная модель, совместимая с Office 15).

## Исправления надёжности

- Сравнение объектов через оператор `Is` (не `Id`+`SlideID` — они пересекаются между файлами)
- Перед Cancel диалога учитываются фигуры, помеченные `MarkSelectedAsTargets`
- В обработчике ошибок сохраняются `Err.Number` / `Description` до закрытия файлов
- `Err.Clear` после блоков `On Error Resume Next` при извлечении признаков
- Без антипримеров сигнатура набирает структурный минимум, а не один бит `Type`
- RGB в сигнатуре нормализован до 6 hex-цифр

## Ограничения (честно)

- «100% в любых будущих презентациях» достижимо, только если у целевого объекта есть **стабильный и отличимый** набор свойств. Два визуально идентичных прямоугольника без текста физически неразличимы.
- Картинки сравниваются по типу/геометрии/оформлению контейнера, **не** по пиксельному хешу изображения (это медленно и хрупко в VBA 2013).
- После сильного ручного изменения фигуры (другой тип, другая относительная геометрия) сигнатура закономерно перестанет совпадать — это ожидаемо.

## Типовой сценарий интеграции

```vba
Public Const MY_TITLE_SIG As String = "S1|...." ' вставить после анализа

Public Sub HighlightTitles()
    Dim sld As Slide, shp As Shape
    For Each sld In ActivePresentation.Slides
        For Each shp In sld.Shapes
            If ShapeMatchesSignature(shp, MY_TITLE_SIG) Then
                shp.Fill.ForeColor.RGB = RGB(255, 230, 150)
            End If
        Next shp
    Next sld
End Sub
```
