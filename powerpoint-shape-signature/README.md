# ShapeSignature — обучаемые сигнатуры фигур для PowerPoint 2013

Идентификация текстовых блоков (колонтитулы, цветные метки Label и любые другие) в презентациях с плохим форматированием.

Работает **офлайн**: без Интернета, без `CreateObject`, без Scripting/MSForms, без внешних DLL — только объектная модель PowerPoint и чистый VBA. Совместимо с Secret Net Studio. В PowerPoint нет `ThisPresentation`, поэтому все методы принимают путь или объект презентации явно.

## Обучение

```vba
Dim sig As String

sig = TrainSignatureFromFiles( _
        "C:\Decks\bad1.pptx;C:\Decks\bad2.pptx;C:\Decks\bad3.pptx", "FooterLabel", _
        "C:\Decks\reference.pptx", "FooterLabel")

Debug.Print sig                  ' S3|AwN7AAYDSCgM7Ag8Dg...
Debug.Print LastTrainReport()    ' что усвоено, что отключено, порог
```

Порядок работы:

1. В каждом обучающем файле назовите нужные фигуры **одним именем** (панель «Область выделения»).
2. Передайте список путей с **неправильным** форматированием через `;` и имя фигуры.
3. Передайте список путей с **правильным** форматированием через `;` и имя фигуры (можно `""`).
4. Получите строку-сигнатуру с накопленным опытом.

Что происходит внутри:

- **оба** набора файлов дают признаки **роли** объекта (что он есть);
- **правильные** файлы дополнительно дают **эталон формата** (как должно быть);
- признак, который «плавает» между примерами, **автоматически отключается** — так неправильное форматирование само исключает ненадёжные признаки, вместо того чтобы попадать в эталон;
- **порог совпадения** вычисляется при обучении и хранится внутри сигнатуры.

Файлы открываются только для чтения, невидимо, и закрываются после обучения. Уже открытые презентации не закрываются.

## Распознавание

```vba
Dim pct As Long
pct = ShapeSimilarityPercent(shp, sig)          ' 0..100

ok = ShapeMatchesSignature(shp, sig)            ' True/False по порогу из сигнатуры
txt = ShapeSimilarityExplain(shp, sig)          ' "78% — совпадение (порог 72%). Совпало: зона, размер…"
dev = DescribeFormatDeviations(shp, sig)        ' "кегль меньше эталона, цвет текста вне эталона."
```

Обе главные функции принимают ровно два аргумента: `ByRef shp As Shape` и `ByVal sig As String`.

## Поиск

```vba
' Один объект на слайд — самый надёжный режим
Set shp = FindBestMatchOnSlide(sld, sig, pct, ambiguous)

' Все совпадения
Set col = FindSimilarShapes(pres, sig)
report = FindSimilarShapesReport(pres, sig)
```

`FindBestMatchOnSlide` возвращает лучшего кандидата и выставляет `ambiguous = True`, если второй кандидат отстаёт менее чем на 10 % — в этом случае автоматическую правку лучше не выполнять.

## Каталог сигнатур

Хранится в тегах презентации-носителя, переносится вместе с файлом, файловая система не нужна:

```vba
SaveSignatureToPresentation pres, "FOOTER", sig
sig = LoadSignatureFromPresentation(pres, "FOOTER")
```

## Признаки и их устойчивость

| Признак | Участие | Почему |
|---|---|---|
| Зона центра фигуры | главный вес | самый устойчивый признак роли |
| Полоса размеров, пропорции | высокий | одна строка / широкий блок |
| Тип фигуры, тип placeholder | высокий | надпись или footer-заполнитель |
| Признаки блока (есть текстовый фрейм, заливка, полужирный, цифры) | средний | «есть выделение» вместо «какой цвет» |
| Структура текста (абзацы, корзина длины) | средний | устойчиво при смене формулировок |
| Относительный кегль | низкий | часто это и есть дефект |
| Содержимое текста, точный RGB, имя шрифта | не используются в роли | меняются; идут только в эталон формата |
| `Name`, `Id` | только вход обучения | ненадёжны между файлами |

Геометрия нормализуется к размеру слайда в точках (1/72"), поэтому результат не зависит от DPI, монитора, ОС и размера листа. Позиция сравнивается как **зона с плавным затуханием**, смещения не обнуляют результат.

## Формат сигнатуры

`S3|<base64url>` — бинарная упаковка с диапазонами, счётчиками примеров, порогом и CRC-24.

| Случай | Длина |
|---|---|
| только роль | ~27 символов |
| роль + эталон формата (типовой колонтитул) | ~61 символ |
| все признаки активны | ~69 символов |

Всегда меньше 100 символов. Проверяется тестом `test_signature_helpers.py`.

## Надёжность

- все публичные функции обёрнуты обработчиками: при сбое возвращается `0`, `False`, `""` или пустая коллекция — вылетов нет;
- временно открытые презентации закрываются даже при ошибке;
- повреждённая или обрезанная сигнатура отклоняется по CRC;
- разбор сигнатуры кешируется, дорогие свойства (текст, шрифт) читаются только у кандидатов, прошедших дешёвый отсев по геометрии и типу.

## Установка

1. `Alt+F11` → File → Import File → `ShapeSignature.bas` (и при желании `ShapeSignatureExamples.bas`).
2. Сохранить презентацию как `.pptm`.
3. Разрешить макросы в Центре управления безопасностью.

Макросы для работы вручную: `TrainSignatureUI`, `TestSimilaritySelected`, `TestFindInActivePresentation`.
